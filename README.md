# Milestone 1: STM 32 Familiriazation (Blinking LED)
For the first milestone of the group project, we had to make the NUCLEO-F446RE LED blink. This milestone familiarize us with the GPIO output by blinking the built in LED on pin LD2 using the STM32CubeIDE.

## Step-by-Step Setup Guide

### Step 1 — Install STM32CubeIDE and STM32CubeMX
- The softwares were downloaded from the official website: [st.com](https://www.st.com/en/development-tools/stm32cubeide.html)
- Installed with default settings.

---
### Step 2 — Created a New Project in STM32CubeMX
- STM32CubeIDE opened
- New project were created by going to **File → New → STM32 Project**
- In the board selector, the development board were searched. (**NUCLEO-F446RE**)
- Selected yes on initialize all peripherals with their default mode option.
- By default, 11 GPIOs were used including the LD2 Green LED pin PA5
- Then we saved the project as STM32 led haha2 and generated the code.

---
### Step 3 — Open the project in STM32CubeIDE
- We opened the project code generated by the STM32CubeMX from before using STM32CubeIDE
- The LED blinking code were written in 'Core/Src/main.c'.
- Inside the while (1) loop, we added:
```c
/* USER CODE BEGIN WHILE */
while (1)
{
    HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);
    HAL_Delay(500);  // 500ms delay — blink every 0.5 seconds
}
/* USER CODE END WHILE */
---
```
### Step 4 — Build the Project
```
Press Ctrl + B
```
Confirmed **"Build Finished. 0 errors"** in the console.

---
### Step 5 — Flash to the Board
```
Press Ctrl + F11
```
- Select **Run As → STM32 C/C++ Application**
- Wait for `"Download verified successfully"` in console

---
### Step 6 — Run the project
- Press the **black RESET button (B2)** on the board
- Watch **LD2 (green LED) blink every 0.5 seconds**

---
## Key takeaways from this project
- At first we were looking at the wrong LED. We thought that there is problem with the coding or the board until we realised that we were looking a the wrong LED. We tested with different delays only to see the LED that blinking red/green didnt delay at all because we thought that was the LED we adjusting. Turned out, when the LED is blinking, its showing that the project is flashing to the board. Then we realised that the LD2 is blinking at the same time as the delay inputted and realised what we were looking at the wrong LED.
